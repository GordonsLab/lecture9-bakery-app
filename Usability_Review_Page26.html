Page 26: usability review

Applied to both bakery apps. This is an AI heuristic review using simulated workflows, not feedback from recruited human users.

Simulated user / taskIssueApplied improvement
First-time baker: start MondayThe first action was clear, but the complete daily sequence was less obvious.Added short steps: fetch, review requests or book help, accept and close.
Busy baker: fetch and then acceptAction buttons could remain disabled after a successful request.Restore controls after requests, retain rule-based disabled controls, and show a busy state.
Baker: accidental rejection, helper booking or day closeNo recovery for a mistaken action.Added persistent, single-step Undo. It restores orders, date, helpers, message imports and history together. Day close and helper booking still ask first. Repeated fetches and failed actions preserve the previous undo point.
Baker: server disconnectedThe error did not describe a complete recovery sequence.Explain how to restart, refresh, and check history before retrying a change. Errors use an alert and a distinct appearance.
Keyboard user: switch schedulesTabs supported clicking but lacked familiar keyboard navigation.In the final app, added Left/Right, Home and End keys for the schedule tabs. The basic app has no staff schedule or Gantt tabs.

Retained strengths

Consistent wording in both apps; hours, price, pickup date and reason near each decision; visible action results; two-day notice and capacity checks; original message outcomes; date selector; order detail tables as an alternative to the Gantt chart.

Verification and limits

Regression tests cover complete state restoration after acceptance, rejection, helper booking and closing a day, plus repeated fetches and invalid actions. Existing full-week capacity and schedule tests remain in place. Browser review checks the new controls and keyboard tab selection. No human usability study has been conducted. Undo covers only the latest successful change; it is not a multi-step history or redo feature. The Gantt chart still uses the documented assumed shifts and baking durations.
